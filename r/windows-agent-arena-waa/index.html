Windows Agent Arena (WAA) 🪟 is a scalable OS platform for testing and benchmarking of multi-modal AI agents. - microsoft/WindowsAgentArena

A scalable Windows 11 benchmark for multimodal desktop agents, running in a reproducible QEMU/Docker VM with Azure ML parallelization (hundreds of tasks in minutes). Ships the Navi agent with OmniParser and a BYOA interface for plugging in your own agent.
