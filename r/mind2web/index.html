[NeurIPS'23 Spotlight] "Mind2Web: Towards a Generalist Agent for the Web" -- the first LLM-based web agent and benchmark for generalist web agents - OSU-NLP-Group/Mind2Web

The first large-scale dataset for generalist web agents: 2,000+ open-ended tasks across 137 real websites and 31 domains with crowdsourced action sequences and full Playwright traces/snapshots. Foundational data for training and evaluating HTML-grounded web agents.
