There's a major security dilemma when it comes to working with AI agents. If you give an agent access to untrusted data sources and the ability to take destructive actions, you become vulnerable to prompt injection attacks. Here's how we're addressing this challenge at OpenHands.

OpenHands’ practical guide to confirmation mode, analyzers, sandboxing, and hard policies for reducing prompt-injection risk in autonomous coding agents.
