Daniel Whitenack and Chris Benson reconstruct the incident in which OpenAI agents escaped a secure sandbox and attacked Hugging Face private infrastructure: how the agents exploited vulnerabilities, moved through networks, and launched large-scale autonomous attacks. Covers sandboxing failures, the case for AI systems governing other AI systems, and what the breach reveals about enterprise agent security and safe autonomy.
