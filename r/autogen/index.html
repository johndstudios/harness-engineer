A programming framework for agentic AI

A programming framework for agentic AI. Contribute to microsoft/autogen development by creating an account on GitHub.

A pioneering multi-agent framework (now in maintenance mode, succeeded by Microsoft Agent Framework) with a layered Core/AgentChat/Extensions architecture, local and distributed runtimes, AutoGen Studio no-code GUI, and AutoGen Bench evaluation suite. Widely cited as a reference design for event-driven multi-agent runtimes.
