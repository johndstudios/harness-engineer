Letta (formerly MemGPT)

https://github.com/letta-ai/letta · tool · letta-ai · added 2026-08-02· by John Dilts

A platform for stateful, self-improving agents with advanced memory, exposing an App Server API plus a TypeScript Agent SDK that can run agents on Constellation cloud, fully local, or self-hosted. A reference for building agents whose memory and behavior persist across sessions.
