AndroidWorld is an environment and benchmark for autonomous agents

AndroidWorld is an environment and benchmark for autonomous agents - google-research/android_world

A dynamic benchmarking environment for autonomous agents running on a live Android emulator, with 116 hand-crafted tasks across 20 real apps and millions of parameterized variations. Durable reward signals and extensible task design make it a model for reproducible mobile-agent eval.
