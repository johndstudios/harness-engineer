The reception to our recent post on Code Reviews has been strong. Catch up!

Aaron Levie (Box CEO) on the infrastructure every agent needs: sandboxed “box” workspaces, agent identity and governance, permission models for agent-vs-human data access, and why context engineering (not infinite context windows) is the real bottleneck for enterprise knowledge-work agents. Includes Box’s internal agent eval methodology — rubric-scored retrieval across industry document sets — and the explore/exploit search limits of frontier models.
