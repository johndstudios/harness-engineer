Reflexion: Language Agents with Verbal Reinforcement Learning

https://arxiv.org/abs/2303.11366 · paper · shinn · added 2026-08-02· by John Dilts

Introduces verbal self-reflection stored in an episodic memory buffer to improve agent decision-making across trials without weight updates — a core pattern for harnesses that learn from execution failures.
