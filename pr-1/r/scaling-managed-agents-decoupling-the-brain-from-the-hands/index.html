Scaling Managed Agents: Decoupling the brain from the hands

#context-engineering#security#long-running

Author: AnthropicPublished: 2026-04-08Reading time: ~10 min2084 wordsLanguage: enType: articleCrawled: 2026-11-16

Harnesses encode assumptions that go stale as models improve. See how Managed Agents is built around interfaces that stay stable as harnesses change.

Framing a hosted long-horizon agent as a ‘meta-harness’ with stable interfaces (session, harness, sandbox) inspired by OS virtualization. Covers decoupling brain from hands for resumability, many-brains/many-hands scaling, and why the session log — not the context window — is the durable context object.
