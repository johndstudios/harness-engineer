The enterprise-ready successor to AutoGen for building and orchestrating production multi-agent workflows in Python and .NET, with graph-based orchestration, checkpointing/durability, OpenTelemetry observability, declarative YAML agents, and A2A/MCP interoperability. Built for taking agents from prototype to production with inspectability.
