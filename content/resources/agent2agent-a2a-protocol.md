An open protocol (Linux Foundation, contributed by Google) for interoperability between opaque agents across frameworks, with Agent Cards for discovery, JSON-RPC over HTTP, SSE streaming, and push notifications. Ships Python/Go/JS/Java/.NET/Rust SDKs and defines how independent agent runtimes communicate.
