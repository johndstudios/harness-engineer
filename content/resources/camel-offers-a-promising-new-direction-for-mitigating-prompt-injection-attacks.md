Detailed walkthrough of Google DeepMind's CaMeL (Capabilities for Machine Learning) paper, which converts user prompts into a restricted Python DSL executed by a custom interpreter with capability-based data-flow tainting. The first prompt-injection mitigation Simon endorses as offering 'strong guarantees' rather than probabilistic guardrails.
