Surveys Paul Kinlan's argument and demo that the browser's 30-year-old sandbox — the File System Access API, CSP headers, sandboxed iframes, and WebAssembly workers — is a mature, deterministic alternative to running coding agents in local containers. Concrete techniques (including a double-iframe network-isolation trick) for harnessing untrusted agent execution without a VM.
