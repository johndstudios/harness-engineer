A code-first Python toolkit for building, evaluating, and deploying agents, with a graph-based Workflow Runtime (routing, fan-out/fan-in, loops, human-in-the-loop), a Task API for agent-to-agent delegation, and a built-in eval/Web UI. A first-class runtime for inspectable multi-agent orchestration.
