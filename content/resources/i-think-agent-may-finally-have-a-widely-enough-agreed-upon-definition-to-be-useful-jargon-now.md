Settles on 'an LLM agent runs tools in a loop to achieve a goal' as the working definition, and distinguishes this from unhelpful 'agent-as-employee' framings. Useful shared vocabulary for the harness-engineering field, since the definition centers the harness (tools + loop) rather than anthropomorphic autonomy.
