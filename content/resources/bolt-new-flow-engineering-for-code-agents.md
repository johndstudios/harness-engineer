StackBlitz CEO Eric Simons and Qodo CEO Itamar Friedman dish on building production coding agents: Bolt's WebContainer OS (a from-scratch WASM runtime instrumented for error-capture and self-healing loops), task breakdown flows, and Qodo's AlphaCodium "Flow Engineering" methodology (reason → propose solutions → generate tests → iterate until passing). Concrete patterns for sandboxed execution environments and test-verified agent loops.
