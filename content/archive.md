<p>Harness engineering moves fast. Rather than deleting entries that age out,
we retire them here so old links keep working and you can see what replaced
what.</p>

<ul>
  <li><strong>Superseded</strong> — newer work covers the same ground better. Each entry links to its replacement.</li>
  <li><strong>Archived</strong> — the page is gone or the project is no longer maintained. Links point to a Wayback Machine snapshot.</li>
</ul>

<p>Entries that are dated but still useful stay in the main listings with a
<em>may be outdated</em> badge. See <a href="/contribute/">Contribute</a> for
how to propose a change, or <a href="/link-health/">Link health</a> for
current crawl failures.</p>
